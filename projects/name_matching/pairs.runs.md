Every output row carries a `run_id`. This log records the parameters behind each id, so the
per-row provenance tags are decodable later. Generated by `generate_pairs_batched_workflow.js`

## How to run the chunks (READ FIRST)

Same discipline as the paraphraser project: **do NOT launch all chunks in parallel.** Each
chunk is many subagents × hundreds of name pairs; firing the whole `data/runs/batched/` set at
once would blow through rate limits and give no chance to inspect output between runs.

Run procedure:

1. **One chunk at a time, sequentially.** Invoke a single chunk, wait for it to finish, then
   persist and inspect before starting the next:
   ```
   Workflow({ scriptPath: "<abs>/projects/name_matching/data/runs/batched/chunk_NNN.workflow.js" })
   ```
2. **Persist after each chunk** — append the returned `triples` to `data/pairs.claude-code.jsonl`.
   The result is in-memory only until you write it (use the canonical key order from the schema).
3. **Check `failed` / `mismapped`** in the return value before moving on. As in the paraphraser,
   `mismapped` is dominated by benign echo-variant false positives (quote/case swaps) — spot-check
   a few against the manifest before worrying; real cross-contamination is rare.
4. **Append a row to this log** for the run_id you just completed.
5. **Re-emit, don't hand-edit**, when remaining work changes: `python3 emit_chunks_batched.py`
   with the live `--done-file` repacks only outstanding jobs.

### Threshold tuning (do this after the first real run)

`filter_pairs.py` soft-flag thresholds are **starting points** (mirrors the paraphraser's
BERTScore-threshold caveat — tune against a real distribution before relying on `--strict`):

- `SIM_MIN_SPELLING = 0.45` — below this a typo/nickname/phonetic/translit variant is treated as
  having drifted into a different name. Check the char-similarity distribution of kept spelling-axis
  rows; if legit nickname swaps (Bob↔Robert) routinely score lower, lower the threshold.
- `JACCARD_MIN_STRUCTURAL = 0.34` — token-overlap floor for reorder/initial/format/suffix/cultural
  variants. Heavy abbreviation (first+middle both initialized) legitimately drops overlap.
- `SIM_MAX_NEGATIVE = 0.90` — above this a `non-match` negative is ambiguously similar to the source.
  This is the most important band: a good negative set should be *confusable but distinct*.

Run `filter_pairs.py --jaro` (needs `jellyfish`) for Jaro-Winkler similarity + a Metaphone phonetic
check on phonetic/nickname match rows.
